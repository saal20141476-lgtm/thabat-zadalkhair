# ثبات | زاد الخير

مشروع أندرويد وصفحة تحميل عربية. مفتاح التوقيع وكلمات المرور غير مضمنة في المستودع العام.

قبل تشغيل البناء، أضف أسرار Actions التالية: `THABAT_KEYSTORE_BASE64` و`THABAT_STORE_PASSWORD` و`THABAT_KEY_ALIAS` و`THABAT_KEY_PASSWORD`. لا تنشر قيمها.

فعّل GitHub Pages من Settings → Pages باختيار الفرع `main` والمجلد `/docs`. بعد رفع جميع ملفات المشروع، شغّل سير العمل Build Thabat APK من تبويب Actions.
